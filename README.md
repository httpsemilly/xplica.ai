## Resumo

Esse trabalho propõe o desenvolvimento de um bot para Whatsapp para detecção automática de notícias falsas em português, utilizando técnicas de Machine Learning e Deep Learning com ênfase na comparação entre os modelos SVM e BERTimbau. A ferramenta permite que o usuário inicie uma conversa com o bot e encaminhe uma mensagem com o conteúdo textual a ser verificado. Após a verificação ser realizada, o bot expressa a probabilidade daquela notícia ser inverídica. Para o treinamento dos modelos foi utilizado o conjunto de dados Fake.Br, composto por notícias em português rotuladas como falsas ou verdadeiras, e então foi avaliado o desempenho dos dois modelos apresentados a partir de diferentes métricas, como acurácia, recall, F1-score e tempo de inferência.
